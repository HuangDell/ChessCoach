# ADR-005: Canonical skill evidence

- Status: Accepted
- Date: 2026-08-25

## Decision

Long-term personalization is derived only from versioned, deduplicated observations produced by
analysis and deterministic attempts. Estimates are reproducible projections over that evidence.

## Consequences

The Agent may retrieve and explain evidence, but cannot create observations, promote a weakness, or
modify an estimate. A single error never becomes a recurring weakness.
