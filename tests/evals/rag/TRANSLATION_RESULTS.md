# RAG 实际查询翻译对照（2026-09-14）

本轮执行独立 RAG Benchmark 的中文→英文模型翻译，再复用现有索引检索；
Agent 26 条 portfolio 不参与本轮，也不与这 40 条合并。

## 配置与边界

- 同一 v3/schema 3 语料，670 段；复用 Qwen3-Embedding-8B/CUDA:0 索引，没有重做书籍 embedding。
- corpus fingerprint：`267973c8101a73ac2ff993a71958e9fb44c7a13c2b2950fd20f6df0d9afaf671`。
- index fingerprint：`28f6a07a4661d1b197cbc146132e4148f3279f33dc8a0b6da2ade5e0b294fe64`。
- 翻译：当前配置的自定义 Responses endpoint，模型标识 `gpt-5.6-sol`；沿用厂家默认思考强度。
  不声称核验了 endpoint 背后的模型权重或版本。
- 翻译只读取中文问题与固定提示词，不读取英文参考译文、标注或教材；本轮仍不输入局面上下文。
- 实际译文冻结后供 BM25/dense/hybrid 共用，生产检索参数不变。翻译失败不回退参考译文。
- 40/40 翻译成功、40/40 检索成功。一次运行、无重复采样；不代表生产完整 Agent 的端到端成绩。

## 模型评审

实际译文检索新增 137 个旧标签未覆盖的 query/chunk 对。三个按用户指定配置启动的
`gpt-5.6-sol` / `high` sub-agent 分片审阅：A 53、B 49、C 35；同时分片检查全部40条译文。
审阅材料不提供参考英文、既有等级、检索路由或排名；相关性以原中文问题及可用局面为准。
这是每项由一个审阅者负责的分工评审，不是每项三票投票，也不提供评审者一致性统计。
同模型系列可能有共同偏差，暂不进行人工验收，不把模型评审称为人工标注。

40条译文：39条判为忠实，P02有轻微语义收窄（将“是否选错西班牙开局”译成“是否选错该开局
中的线路”），无严重含义改变或执行失败。137个新候选中19个直接支持、40个背景、78个不支持；
其中14个背景边界标记存疑。合并后共有758条judgments，三组top5的未判断比例均为0。
这只是本轮候选池覆盖，不是全库标注完成；旧标签中的争议也没有因此全部重新验收。

旧 v2 标签保留，新标签输出到 `datasets/zh-en-v3-pooled-live-translation/`。
比较器以同一标签快照重评中文、英文参考、实际英文译文三组，并拒绝不同索引或查询集混比。
`qrels_complete=false`；直接 Hit@5 的分母仍是36条有证据支持题，命中表示至少一段直接支持
一个所问教学点，不代表单段完整回答或当前局面已由 Engine 验证。

实际翻译令本轮hybrid从中文的28/36增至30/36，增加5.56个百分点，与参考英文持平。
具体新增命中P05、P07、R01、R02，丢失G03、G07；相对参考英文则是新增P05、丢失G03。
G03的实际译文仍保留了“受攻击需退”和“赢子”的例外条件，说明忠实翻译也会因措辞变化影响排名。
实际译文的hybrid MRR低于参考英文，也低于同查询的dense，等权RRF仍未显示优于dense的收益。

BM25空候选从中文的27/40降至实际译文的0/40，但其直接Hit@5只有63.89%，
说明英文查询解决了词面检索缺失，并不保证召回内容直接支持问题。
实际译文hybrid仍未命中G03、G07、G08、P03、P04、P06。

本轮只能支持“实际翻译改善了这40题中的部分检索结果”，不能据此宣称泛化提升或自动将翻译接入
生产。分母仅36个有支持题，查询/来源仍是开发诊断集，未进行独立测试集或多次采样验证。
结合下面约4.73秒的额外翻译耗时，当前收益不足以单凭这一轮确定生产方案。

下一步优先对局面题加入确定性校验的必要上下文，使用同一译文/索引做有无上下文对照，
重点检查P03/P04/P06；不能从FEN推断不存在的着法历史或让翻译模型编造Engine评价。
完成这一步后再判断是否调整查询构造或融合参数；当前保留生产检索行为。
